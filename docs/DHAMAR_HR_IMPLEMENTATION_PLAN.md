# خطة تنفيذ DUTY TRACK — إدارة القوة البشرية، السجن المركزي بذمار

## النطاق
نظام إداري للقوة البشرية وإعداد التقارير للمدير العام. لا تُستخدم البيانات الحقيقية في بيئة الاختبار.

## مبادئ إلزامية
- صلاحيات قائمة على الأدوار، وفحصها على الخادم وقواعد Firestore وليس الواجهة فقط.
- عدم عرض بيانات الأفراد إلا للمصرح لهم؛ تشفير النقل، سجل تدقيق غير قابل للتعديل من المستخدم العادي، نسخ احتياطية واختبار الاستعادة.
- جميع التقارير تعتمد على بيانات موحدة ومؤرخة، مع إظهار وقت الإنشاء ومصدر الأرقام وحالة الاعتماد.
- عدم حذف السجلات التاريخية؛ أرشفة وتوثيق التصحيحات.
- الاختبارات والتحليل والبناء شرط قبل دمج أي تعديل في main.

## مراحل التنفيذ ومعايير القبول
1. **الاستقرار والأمان:** flutter analyze و flutter test والبناء دون أخطاء، إصلاح التنقل وتسجيل الخروج، مراجعة قواعد Firestore، إدارة الجلسات والأدوار.
2. **ملفات الأفراد:** إنشاء وتعديل وأرشفة وبحث وتصفية؛ منع تكرار الرقم العسكري والهوية مع اختبار التزامن؛ تاريخ الرتب والأقسام.
3. **الخدمات اليومية:** إنشاء مناوبات وتعديلها، استعادة المكلفين عند التحرير، منع ازدواج الإسناد والتعارض مع الإجازات، قائد واحد، كشف قابل للطباعة.
4. **الحضور والإجازات:** حالات حضور يومية، طلبات إجازة واعتمادها، احتساب المدة والرصيد حسب اللوائح المحلية التي تعتمدها الإدارة.
5. **التقارير:** يومي، يومان، شهري، بيان القوة، بيان الخدمات، الغياب والإجازات؛ PDF وExcel؛ معاينة ومطابقة المجاميع، واعتماد قبل الرفع.
6. **لوحة المدير العام:** ملخصات مع تاريخ آخر تحديث، صلاحية قراءة أو اعتماد، سجل التقارير المرفوعة.
7. **القبول:** اختبار أدوار المستخدمين، البيانات الكبيرة، العمل دون اتصال إن كان مطلوباً، النسخ الاحتياطي والاستعادة، وطباعة عربية RTL.

## دورة التقرير
مسودة ← تدقيق مدير القوة البشرية ← اعتماد ← إصدار PDF/Excel برقم وتاريخ ← أرشفة نسخة غير قابلة للتعديل.

## مؤشرات أساسية
إجمالي القوة؛ على رأس العمل؛ حاضر؛ غائب؛ إجازة؛ مهمة؛ مكلف بخدمة؛ غير مكلف؛ بيانات ناقصة.
يجب تعريف الفئات المتداخلة بدقة حتى لا تُجمع على نحو يكرر الشخص نفسه.

## ملاحظات التوافق
BUSINESS_REQUIREMENTS.md يذكر تعز بينما docs/SYSTEM_REQUIREMENTS.md يذكر ذمار؛ يعتمد نطاق ذمار هنا، ويجب توحيد المستندات بعد مراجعة المالك.

## التقارير الثلاثة المطلوبة للمدير العام
- PDF: نسخة رسمية للطباعة والتوقيع والأرشفة، عربية RTL.
- Excel XLSX: بيانات وجداول قابلة للفرز والتحليل، مع صف إجماليات مطابق للتقرير.
- PowerPoint PPTX: عرض إداري موجز بمؤشرات ورسوم بيانية، لا يضم معلومات شخصية غير ضرورية.
- الأنواع: يومي موحد، يومان، شهري، بيان القوة، الحضور والغياب، الإجازات، المناوبات، المهام، التدريب، المقارنات.
- جميع الصيغ من نموذج بيانات موحد وبنفس فترة التقرير ومعرف الإصدار وتاريخ الاستخراج.
- يجب التحقق من اكتمال البيانات قبل التصدير وإظهار الحالات غير المصنفة؛ عدم حساب الأرقام بالتخمين.
- مسار الموافقة: إعداد مدير القوة البشرية، مراجعة، اعتماد، تصدير، أرشفة، سجل تدقيق.
- الوضع الحالي: يوجد PDF وExcel في واجهة معاينة التقرير؛ PPTX يحتاج خدمة توليد وتكامل واجهة واختبارات مستقلة.
